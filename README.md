# Grade Calculator

This is a simple grade calculator web app created using Code.org App Lab and exported to GitHub.

## What it does
- Lets users input assignment grades
- Calculates final grade based on inputs
- Displays results instantly on screen

## How to use
Open `index.html` in a browser to run the app.

## Project files
- `index.html` – Structure of the app (buttons, inputs, layout)
- `style.css` – Styling and design
- `code.js` – All logic and calculations
- `applab/applab.js` – Required Code.org App Lab library
- `applab/applab.css` – Default App Lab styles
- `assets/` – Images and sounds used in the app

## Notes
This project was originally built in Code.org App Lab and exported for use as a web project.
